Model Prefetch Walkthrough

Cache DeepSeek-V2-Lite-Chat on one GPU node before starting inference. This shared preparation serves both the Elastic EP and External DP walkthroughs. The output below was captured with node model delivery enabled.

Summary

NodeModelStore, ModelArtifact and ModelPrefetch verify and cache Hugging Face weights on the node’s disk before a serving Pod starts, so the rollout finds warm, checksum-verified weights and does not wait on a hub download. This shared preparation serves both the Elastic EP and External DP walkthroughs.

Object Scope Creator Purpose
ModelArtifact namespace user the weight files to cache and their revision
ModelStore cluster administrator the nodes that hold cached weights
ModelStoreBinding namespace administrator how much the namespace may cache, and the right to pin
ModelPrefetch namespace user warming the artifact onto the store’s nodes
ModelDeployment namespace user the serving workload that finds the weights warm

Environment

The captured run used this setup:

Item Captured setup
Cluster Kubernetes with GPUStack, node model delivery enabled
Node one GPU node, named gpu-node in the manifests, with disk for the weights
Model deepseek-ai/DeepSeek-V2-Lite-Chat at revision 85864749cd611b4353ce1decdb286193298f64c7

Step 1: Create artifact and prefetch

Enable node model delivery and select the GPU node before applying the manifest (kubectl, jq, access to cluster-scoped model stores, and enough disk for the weights are required).

Save the following as model-delivery.yaml. Replace both gpu-node values with your GPU node’s kubernetes.io/hostname label. The store grant and the prefetch placement must select that same node. The fixed file list resolves to 12 files and 31,418,807,311 bytes.

yaml
apiVersion: v1
kind: Namespace
metadata:
  name: gpustack-elastic
---
apiVersion: worker.gpustack.ai/v1
kind: ModelArtifact
metadata:
  name: deepseek-v2-lite-chat
  namespace: gpustack-elastic
spec:
  source:
    huggingFace:
      repository: deepseek-ai/DeepSeek-V2-Lite-Chat
      revision: 85864749cd611b4353ce1decdb286193298f64c7
  allowPatterns:
    - model-00001-of-000004.safetensors
    - model-00002-of-000004.safetensors
    - model-00003-of-000004.safetensors
    - model-00004-of-000004.safetensors
    - config.json
    - configuration_deepseek.py
    - generation_config.json
    - model.safetensors.index.json
    - modeling_deepseek.py
    - tokenization_deepseek_fast.py
    - tokenizer.json
    - tokenizer_config.json
---
apiVersion: worker.gpustack.ai/v1
kind: ModelStore
metadata:
  name: rtx6000-models
spec:
  nodeSelector:
    matchLabels:
      kubernetes.io/hostname: gpu-node
---
apiVersion: worker.gpustack.ai/v1
kind: ModelStoreBinding
metadata:
  name: rtx6000-models
  namespace: gpustack-elastic
spec:
  storeRefs:
    - name: rtx6000-models
  quota:
    bytes: 64Gi
---
apiVersion: worker.gpustack.ai/v1
kind: ModelPrefetch
metadata:
  name: deepseek-v2-lite-chat
  namespace: gpustack-elastic
spec:
  artifactRef:
    name: deepseek-v2-lite-chat
  bindingRef:
    name: rtx6000-models
  placement:
    nodeSelector:
      matchLabels:
        kubernetes.io/hostname: gpu-node
  minReady: 1

Step 2: Verify the cached model

bash
kubectl apply -f model-delivery.yaml
kubectl -n gpustack-elastic get modelartifacts,modelprefetches
kubectl -n gpustack-elastic get modelprefetch deepseek-v2-lite-chat -o yaml
kubectl get nodemodelstores -o json

Step 3: Start a serving workload

Continue with Elastic EP to grow one collective, or External DP to route requests across fixed DP ranks. Use the namespace and artifact created here in either manifest.

Step 4: Pin weights against eviction

The node cache removes unreferenced weights, oldest first, when usage passes the high watermark. Pinning keeps a digest out of that collection. Admission refuses retention.pinned on a prefetch whose ModelStoreBinding does not set allowPinned, so the administrator grants the right first.

Edit model-delivery.yaml. The grant changes as follows:

diff
 apiVersion: worker.gpustack.ai/v1
 kind: ModelStoreBinding
 metadata:
   name: rtx6000-models
   namespace: gpustack-elastic
 spec:
   storeRefs:
     - name: rtx6000-models
   quota:
     bytes: 64Gi
+  allowPinned: true

The prefetch then asks for the pin:

diff
 apiVersion: worker.gpustack.ai/v1
 kind: ModelPrefetch
 metadata:
   name: deepseek-v2-lite-chat
   namespace: gpustack-elastic
 spec:
   artifactRef:
     name: deepseek-v2-lite-chat
   bindingRef:
     name: rtx6000-models
   placement:
     nodeSelector:
       matchLabels:
         kubernetes.io/hostname: gpu-node
   minReady: 1
+  retention:
+    pinned: true

Run kubectl apply -f model-delivery.yaml again. The file lists the grant before the prefetch, so the grant is in place when the prefetch is admitted. A pinned digest is never a collection candidate on the target nodes, though it still counts toward the store’s usage. See Pinning and expiry .

Step 5: Release the cache

Keep the prefetch while a serving application needs the cached weights. After deleting those consumers, remove the dedicated resources:

bash
kubectl -n gpustack-elastic delete modelprefetch deepseek-v2-lite-chat
kubectl -n gpustack-elastic delete modelstorebinding rtx6000-models
kubectl -n gpustack-elastic delete modelartifact deepseek-v2-lite-chat
kubectl delete modelstore rtx6000-models

Cache collection follows the retention rules . Deleting these CRs does not delete the Kubernetes cluster or its disks.

Limitations

The prefetch warms one node (minReady: 1); serving Pods scheduled onto nodes outside placement.nodeSelector find no warmed cache. High-watermark eviction order, pin behavior (Step 4 ), and retention.ttlAfterLastUse expiry are covered in Pinning and expiry and References, restart, collection .

Troubleshooting

Symptom Signal Check & Mitigation
ModelArtifact resolution failed Condition: Resolved=False/AccessDenied Private or gated repository; check namespace Secret token and inspect InvalidToken event
ModelArtifact resolution failed Condition: Resolved=False/RevisionNotFound Branch, tag, or commit hash misspelled (ModelScope does not default silently to master)
ModelArtifact resolution failed Condition: Resolved=False/SourceUnavailable Hub endpoint unreachable, large directory enumeration timeout, or 5xx network error
ModelArtifact resolution failed Condition: Resolved=False/EmptyManifest Allow/ignore pattern filters excluded all files; review the glob patterns
Model deployment blocked at Starting Condition: WeightsReady=False/NodeDeliveryUnavailable CSI driver model.csi.gpustack.ai missing or modelManager.enabled: false in Helm values
ModelDeployment blocked with pattern filters Condition: WeightsReady=False/FilterNeedsNodeDelivery Pattern filtering requires Node delivery mode; set model-artifact-delivery-mode: Node
Pod stuck in ContainerCreating Condition: WeightsReady=False/Materializing The node plugin is actively downloading; check Pod FailedMount event for downloaded byte count
Weight download failed on node Condition: WeightsReady=False/MaterializationFailed Check kubectl get nodemodelstore <node> -o yaml for digest failure reason, message, and retryTime
ModelPrefetch fails to reach Available Condition: Degraded=True/NodeFailed One or more target nodes failed download; check node disk capacity and logs
ModelPrefetch shows fewer ready nodes than minReady Condition: Lapsed=True/RetentionTTLExpired Node copies went unused past retention.ttlAfterLastUse, left readyNodes and released any pin, and nothing re-warms them; raise or remove the TTL
New ModelPrefetch rejected at admission Over quota or unauthorized Prefetch exceeds ModelStoreBinding quota.bytes, sets retention.pinned without allowPinned: true, or targets undeclared store
Peer sync downloads continuously from Hub modelManager.port: 0 or peer sync disabled Verify setting model-store-peer-sync: true and node spec.peerSyncEnabled: true
